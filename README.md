# Folio

A personal flipbook web app for looking at illustrations the way they're meant to be seen — in a book.

> Work in progress. See `context/project-prd.md` for the vision and `tasks/TASKLIST.md` for the build plan.

## Development

```sh
npm install
npm run dev     # http://localhost:5173
npm run build
npm run lint
npm run test
```

Environment variables are only needed for Google Drive sync (Phase 07). See `.env.example`.
